# Gravity Digital

Landing page en español para Gravity Digital, con Next.js App Router, React,
TypeScript y Tailwind CSS.

## Desarrollo

```bash
npm install
npm run dev
```

## Comprobaciones

```bash
npm run lint
npm run build
```

## Contenido y datos

Los textos principales, servicios, preguntas frecuentes, pasos de atención,
slogan, cobertura y canales oficiales de contacto están en
`src/lib/site-config.ts`. El logo se encuentra en `public/gravity-mark.png`.

La sección de contacto enlaza al WhatsApp, correo electrónico e Instagram
confirmados por el emprendimiento. No hay formulario de envío, backend ni
analítica. No se publican precios, promociones, testimonios, estadísticas ni
certificaciones sin confirmación.

La imagen de soporte remoto se sirve localmente desde `public/remote-support.jpg`
y se usa bajo la licencia de Unsplash: https://unsplash.com/license.

Los iconos de ChatGPT, Claude, Gemini, n8n, Instagram, WhatsApp y Gmail están
guardados en `public/brands/`. Proceden de Simple Icons
(https://simpleicons.org/), excepto el símbolo de ChatGPT, tomado de Wikimedia
Commons (https://commons.wikimedia.org/wiki/File:ChatGPT_logo.svg).
